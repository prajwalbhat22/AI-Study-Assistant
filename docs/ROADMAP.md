# AI Study Assistant - Roadmap

## Completed Features
- User registration and login with JWT authentication
- Secure Spring Boot backend with Spring Security
- MySQL database integration using Spring Data JPA
- Topic management: create, view, update, delete
- Notes management under topics
- Study material upload, download, list, and delete
- Dashboard statistics API
- React frontend with protected routes
- AI features: summary, quiz, flashcards, chat, and study plan
- Gemini API integration with fallback mock AI service

## Current Tech Stack
- Frontend: React, Vite, Tailwind CSS, Axios
- Backend: Java, Spring Boot, Spring Security, JWT
- Database: MySQL
- Tools: Git, GitHub, Postman, VS Code

## Upcoming Features
- User profile update
- Change password feature
- AI chat history storage
- Better dashboard charts
- Search and filter for notes/materials
- Deployment of backend and frontend
- Admin panel
